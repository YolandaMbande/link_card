# Personal Link Page

A simple, responsive personal link page inspired by Linktree, built with HTML and CSS.

This page serves as a central hub for my social media profiles, developer platforms, portfolio, and contact information.

## Features

* Responsive design for desktop, tablet, and mobile
* Light and dark mode
* Persistent theme preference using `localStorage`
* Social media and developer platform links
* Bootstrap Icons integration
* Custom profile image
* Smooth hover and transition effects
* Simple, lightweight setup with no frameworks or build tools required

## Built With

* HTML5
* CSS3
* JavaScript
* Bootstrap Icons

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YolandaMbande/link_card.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd link-page
```

### 3. Add your profile image

Place your profile image inside the `images` folder and update the image path in `index.html` if necessary.

### 4. Customize your links

Open `index.html` and replace the existing URLs with your own social media profiles, website, and contact information.

### 5. Open the page

Open `index.html` in your browser.

No installation or build process is required.

## Customization

You can easily customize:

* Profile photo
* Name and bio
* Social links
* Icons
* Background colours
* Link colours
* Font
* Light and dark mode styling

Brand-specific icons can be added using Bootstrap Icons or Font Awesome.

## Theme Toggle

The page includes a light/dark mode toggle. The selected theme is saved using the browser's `localStorage`, so the visitor's preference is remembered when they return to the page.

## Deployment

The page can be deployed using services such as GitHub Pages, Netlify, or Vercel.

Once deployed, the URL can be added to social media profiles as a single link containing all personal and professional platforms.
